Code to be used with output from Med Associates Boxes with capacitive lickometers (txt files)
Place all txt files from one group for an experiment together in the same folder (eg controls for 60 minute food access with IP saline treatment).
Run the code, and a pop-up will ask what the baseline is before access to the bottle was provided.
There will be a prompt to select the appropriate folder of txt files.
This will save an excel file with "lick_analysis_results"
