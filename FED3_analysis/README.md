This code works with .csv files generated by FED3 devices on the "free-feeding" setting provided by the manufacturer.

Update the pathway to a file with the .csv files in data_dir.

Designate a pathway to an excel "decoder" file with information about each .csv file. The excel sheet should have the following format:
```
Animal  Device Number  NightDate  Condition
CGRP1       7          2/2/2026   Treatment1
CGRP1       7          2/3/2026   Treatment2
```
Adjust the following variable based on experiment:
DARK_HOUR = 17 (time of the dark-cycle onset)
Window_hours = 2 (time window after dark_hour that you want to analyze)
Meal_gap_min = 5  (in minutes: defines a meal)
Min_meal_pellets = 3 (minimum number of pellets required to be counted as a meal)

Run the code. Will save summary data for each animal in an excel file. 
Will detect jams based on an excessive number of detected "motor_turns". Can adjust this threshold with "jam_turns_thresh".
